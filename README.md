# Nosiphus Custom Blocks

This mod adds an assortment of random blocks and items you can use to decorate your world such as colored planks, clothing, and more!

# Brief Content Overview
Nosiphus Custom Blocks adds various blocks and items you can use for decoration. It has no primary overarching theme, but mainly consists of blocks that we use on our own server. There will be blocks that don't make much sense outside of that context, but it also has plenty of blocks that everyone will enjoy using. NCB implements several features from the [TARDIM Texture Pack](https://www.planetminecraft.com/project/tardim---time-and-relative-dimension-in-minecraft/) by UnlimitedMind42, something we enjoyed years ago.

# Current Features
### Armor
Fully dyeable versions of the bow ties and fezzes from the [TARDIM Texture Pack](https://www.planetminecraft.com/project/tardim---time-and-relative-dimension-in-minecraft/) by UnlimitedMind42. Textures used with permission.

### Blocks
Ceiling light variants of glowstone and sea lanterns. If [YogMod](https://www.curseforge.com/minecraft/mc-mods/yogmod) is installed, fluorescent panel variants also become available.
Colored planks, as well as buttons, fences, fence gates, pressure plates, slabs, and stairs. If [YogMod](https://www.curseforge.com/minecraft/mc-mods/yogmod) is installed, beige variants also become available.
TARDIS doors, slabs, and golden roundel blocks from the [TARDIM Texture Pack](https://www.planetminecraft.com/project/tardim---time-and-relative-dimension-in-minecraft/) by UnlimitedMind42. Textures used with permission.

### Food
Custard and fish fingers from the [TARDIM Texture Pack](https://www.planetminecraft.com/project/tardim---time-and-relative-dimension-in-minecraft/) by UnlimitedMind42. Textures used with permission.

### Weapons
Tenth and Eleventh Doctor variants of the sonic screwdriver, which currently work just as swords, from the [TARDIM Texture Pack](https://www.planetminecraft.com/project/tardim---time-and-relative-dimension-in-minecraft/) by UnlimitedMind42. Textures used with permission.
